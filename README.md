# CursorVault

> Windows 鼠标光标主题管理与替换工具

Python 3.10+ · PyQt6 · MIT License

---

## 快速开始

```bash
pip install -r requirements.txt
python -m cursorvault
```

> 替换系统游标需要**管理员权限**。

## 使用

- 从 [致美化](https://zhutix.com/tag/cursors/) 下载游标包 → 解压到 `themes/imported/` → 启动程序 → 选择主题 → 应用
- 文件 → 导入游标目录 / 备份当前游标 / 恢复游标
- 支持 .rar/.zip/.7z 自动解压导入
