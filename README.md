# CursorVault 鼠标素材库

Windows 上换鼠标指针的小工具。在线找主题、本地导入、一键套到系统，重启也还在；还能备份、恢复。

运行环境：Python 3.10+，Windows 10/11。

## 快速开始

```bash
pip install -r requirements.txt
python -m cursorvault
```

懒得记命令的话：`python main.py` 也行。

## 功能

- **在线素材库**：浏览、搜索、分页下载光标主题；下载状态实时可见
- **下载队列**：多个素材可同时下载，侧边栏「下载队列」页实时看进度，一个也不漏
- **本地主题**：点一下预览，再「应用到系统」，重启后依然生效
- **导入 / 备份 / 恢复**：支持 `.cur` / `.ani` 目录导入与整包（zip / rar / 7z）安装；换之前先「备份当前游标」，出问题一键恢复
- **自动更新**：启动时静默检查新版本，发现更新才提示

## 使用提示

- 素材源站未提供公开下载链接的主题，软件内会提示原因（例如需要 VIP 权限），不会绕过源站限制
- 在线素材版权归原作者 / 原站点所有，下载后请仅作个人学习交流使用，商用前请自行确认授权
- 装 `.rar` / `.7z` 包时电脑上最好有 7-Zip 或 UnRAR，不然可能解不开
- 程序会在本地创建主题、缓存、备份目录，这些不会进入版本仓库

## 常见问题

**提示「需要VIP才能下载」或下载失败？**
源站没给公开下载链接（或网络抽风），软件里没法直接下；可稍后重试，或到素材页手动下载后用「导入」安装。

**rar 装不上？**
先装 7-Zip / UnRAR，或者自己解压完再用「导入游标目录」。

**显示「部分 x/15」？**
没凑齐 15 种指针而已，照样能用，缺的保持系统默认。

**重启后主题还在吗？**
在。写进了当前用户设置，第一次更换前建议先备份。
