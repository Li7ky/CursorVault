# CursorVault

Windows 上换鼠标指针用的小工具。在线找主题、本地导入、一键套到系统，重启也还在；还能备份、恢复。

运行环境：Python 3.10+，Windows 10/11。

## 快速开始

```bash
pip install -r requirements.txt
python -m cursorvault
```

懒得记命令的话：`python main.py` 也行。

## 怎么用

- 打开「在线素材库」挑喜欢的下载安装（有的素材要权限，软件里下不了）
- 「本地主题」里点一下预览，再「应用到系统」
- 自己有 `.cur` / `.ani` 文件夹：菜单里「导入游标目录」
- 换之前建议先「备份当前游标」，出问题还能恢复

装 `.rar` 包的话，电脑上最好有 7-Zip 或 UnRAR，不然可能解不开。

程序自己会在本地建主题、缓存、备份文件夹，这些不会跟着仓库一起发。

## 常见问题

**提示「需要VIP才能下载」？**  
源站没给公开下载链接，软件里没法直接下。

**rar 装不上？**  
先装 7-Zip / UnRAR，或者自己解压完再用「导入游标目录」。

**显示「部分 x/15」？**  
没凑齐 15 种指针而已，照样能用，缺啥就还是系统原来的。

**重启后主题还在吗？**  
在。写进当前用户设置了。第一次换之前最好备份一下。

**检查更新没弹窗？**  
点菜单「检查更新」会出结果；开机自动检查的话，只有发现新版本才弹。
