# 🖱️ CursorVault 光标衣柜

**给鼠标换套新衣服，玩坏了还能一键穿回去。**

换鼠标光标这件小事，如今也讲究起来了。👆 手滑了还能一键还原，妈妈再也不用担心我把系统折腾花了。✨

## 🚀 三秒上手

```bash
pip install -r requirements.txt
python main.py
```
